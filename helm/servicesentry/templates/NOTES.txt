1. Open the web panel:

{{- if eq .Values.web.service.type "LoadBalancer" }}
   kubectl get svc {{ include "servicesentry.fullname" . }}-web -n {{ .Release.Namespace }} -w
   # then browse to the EXTERNAL-IP on port {{ .Values.web.service.port }}
{{- else if eq .Values.web.service.type "NodePort" }}
   kubectl get svc {{ include "servicesentry.fullname" . }}-web -n {{ .Release.Namespace }}
{{- else }}
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "servicesentry.fullname" . }}-web 8080:{{ .Values.web.service.port }}
   # then browse to http://localhost:8080
{{- end }}

   Login: {{ .Values.auth.username }} / (the password you set in .Values.auth.password)

{{- if not .Values.control.enabled }}

2. The distributed control poke is DISABLED (control.enabled=false): service control
   propagates via the periodic DB reconcile (no instant poke). Set control.token to
   enable it.
{{- else if and (not .Values.control.token) .Values.existingSecret }}

2. control.enabled=true with existingSecret and no control.token: the chart cannot tell
   whether your Secret carries SS_CONTROL_TOKEN, so the control ports are not probed. Put
   the token in that Secret (e.g. `openssl rand -hex 32`) for the instant poke.
{{- else if not .Values.control.token }}

2. control.token was empty: the deployed one was reused, or (generateSecrets=true) a random
   one was generated into the release Secret and is kept across `helm upgrade`.
{{- end }}

{{- if and .Values.generateSecrets (or (not .Values.secretKey) (not .Values.control.token)) }}

NOTE: generateSecrets=true — values left empty were generated or reused from the live Secrets.
   That only holds with `helm install`/`helm upgrade`. Never render this release with
   `helm template` or a GitOps tool: there every render generates a NEW secretKey, and the
   secrets already stored in the database can no longer be decrypted. Copy the key out
   (kubectl get secret {{ include "servicesentry.fullname" . }}-secretkey -o jsonpath='{.data.flask_secret}' | base64 -d)
   and set it as secretKey before you do.
{{- end }}

{{- if and (ne .Values.database.driver "sqlite") (not .Values.database.host) }}

WARNING: database.host is empty. Point it at your MySQL/PostgreSQL.
{{- end }}

{{- if not .Values.persistence.enabled }}

WARNING: persistence.enabled=false — /var/lib/ServiSesentry is an emptyDir. Backups, uploaded
pictures, MIBs and SNMP profiles are lost whenever a pod is replaced and are not shared
between pods. Set persistence.enabled=true (ReadWriteMany storage) or persistence.existingClaim.
{{- end }}
