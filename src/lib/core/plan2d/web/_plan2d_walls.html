{# ================================================================ plan2d — los muros de un plano de fondo, leídos de su imagen, y la geometría de sus tramos. Se pidió que el plano de fondo diera los muros, en vez de tener que dibujarlos. Lo que se hace aquí es leerlos: la imagen se mira en el navegador —sin librerías— buscando trazos oscuros con el grosor de un muro, rectos y largos. Lo que sale es una PROPUESTA: quien la revisa acepta, borra, alarga o dibuja lo que falte. Un plano trae cotas, textos, rayados y muebles que se parecen a un muro, y escaneado trae sombras; lo que pasa los filtros es casi siempre un muro. Lo que se busca, en píxeles de la imagen, sale de su calibración (`_plan2d_bg.html`): con la escala dicha, un muro mide de 6 a 70 cm de grueso y más de 60 cm de largo, y eso se pasa a píxeles (`p2dWallsParams`). Todo es puro —una imagen o unos tramos dentro, tramos fuera—: no sabe de qué plano es, ni dónde se guardan los muros, ni cómo se revisan. Un tramo es `{x1, y1, x2, y2, t}` en píxeles al leer, y `{kind, x1, y1, x2, y2, thick_mm}` en milímetros del plano una vez revisado. ================================================================ #} // ── Leer el plano ──────────────────────────────────────────────────────────── /** El umbral de Otsu: el gris que mejor separa el trazo del fondo. */ function p2dWallsOtsu(lum) { const hist = new Array(256).fill(0); for (let i = 0; i < lum.length; i++) hist[lum[i]]++; const total = lum.length; let suma = 0; for (let i = 0; i < 256; i++) suma += i * hist[i]; let sB = 0, wB = 0, mejor = 0, umbral = 128; for (let i = 0; i < 256; i++) { wB += hist[i]; if (!wB) continue; const wF = total - wB; if (!wF) break; sB += i * hist[i]; const mB = sB / wB, mF = (suma - sB) / wF; const entre = wB * wF * (mB - mF) * (mB - mF); if (entre > mejor) { mejor = entre; umbral = i; } } return umbral; } /** Los tramos de muro de una imagen: `[{x1, y1, x2, y2, t}]` en píxeles, `t` su grueso. * * Horizontales y verticales por separado, con la misma cuenta girada: por cada fila, los trozos * oscuros de al menos `minLen` seguidos; las filas contiguas cuyos trozos se solapan son el * mismo trazo, y su número de filas es su grueso. Un trazo de entre `minT` y `maxT` filas es un * muro; más fino es una cota, un texto subrayado, una línea de mobiliario; más grueso es una * mancha —una columna rellena, un rayado—. Luego los tramos alineados con un hueco pequeño se * juntan: un muro cortado por una mancha del escaneo es un muro. Los muros en diagonal no se * leen: se dibujan a mano. Pura: probada en node con imágenes hechas a medida. */ function p2dWallsDetect(img, o) { const W = img.width, H = img.height, d = img.data; const lum = new Uint8Array(W * H); for (let i = 0, p = 0; i < W * H; i++, p += 4) { // Lo transparente es fondo, no negro. lum[i] = d[p + 3] < 128 ? 255 : Math.round(0.299 * d[p] + 0.587 * d[p + 1] + 0.114 * d[p + 2]); } const otsu = p2dWallsOtsu(lum); const umbral = o.thresh === null || o.thresh === undefined ? otsu : o.thresh; const oscuro = (x, y) => lum[y * W + x] < umbral; const minLen = Math.max(4, Math.round(o.minLen)), minT = Math.max(1, Math.round(o.minT)); const maxT = Math.max(minT, Math.round(o.maxT)), hueco = Math.max(0, Math.round(o.gap || 0)); // Los trazos de una orientación. `n` filas de `m` píxeles; `at(i, j)` es la fila i, columna j. const bandas = (n, m, at) => { const abiertas = [], hechas = []; for (let i = 0; i <= n; i++) { const tramos = []; if (i < n) { let j = 0; while (j < m) { if (!at(i, j)) { j++; continue; } let k = j; while (k < m && at(i, k)) k++; if (k - j >= minLen) tramos.push([j, k - 1]); j = k; } } const siguen = []; for (const b of abiertas) { // Solapándose en la mitad del MÁS LARGO, no del más corto. Reportado con un plano // real: cada tabique acaba en un pilar macizo dibujado, un cuadrado de su ancho // y algo más; con la mitad del más corto, el cuadrado se unía al trazo del muro, // las columnas del pilar contaban como grueso, y el muro salía de doce píxeles // —«demasiado grueso»— y se perdía. Faltaban todos los tabiques de las oficinas. const t = tramos.findIndex(([a, z]) => Math.min(z, b.z) - Math.max(a, b.a) >= Math.max(z - a, b.z - b.a) * 0.5); if (t >= 0) { const [a, z] = tramos.splice(t, 1)[0]; b.a = Math.min(b.a, a); b.z = Math.max(b.z, z); b.fin = i; siguen.push(b); } else hechas.push(b); } for (const [a, z] of tramos) siguen.push({ini: i, fin: i, a, z}); abiertas.length = 0; abiertas.push(...siguen); } return hechas.map(b => ({c: (b.ini + b.fin) / 2, t: b.fin - b.ini + 1, a: b.a, z: b.z})) .filter(b => b.t >= minT && b.t <= maxT); }; // Juntar tramos alineados (misma `c` a medio grueso) separados por menos de `hueco`. const juntar = (lista) => { lista.sort((p, q) => (p.c - q.c) || (p.a - q.a)); const out = []; for (const b of lista) { const prev = out.find(x => Math.abs(x.c - b.c) <= Math.max(2, Math.max(x.t, b.t) / 2) && b.a - x.z <= hueco && x.a - b.z <= hueco); if (prev) { prev.a = Math.min(prev.a, b.a); prev.z = Math.max(prev.z, b.z); prev.t = Math.max(prev.t, b.t); } else out.push(Object.assign({}, b)); } return out; }; const horiz = juntar(bandas(H, W, (y, x) => oscuro(x, y))); const vert = juntar(bandas(W, H, (x, y) => oscuro(x, y))); const out = horiz.map(b => ({x1: b.a, y1: b.c, x2: b.z + 1, y2: b.c, t: b.t})) .concat(vert.map(b => ({x1: b.c, y1: b.a, x2: b.c, y2: b.z + 1, t: b.t}))); out.umbral = umbral; // el gris que se usó out.otsu = otsu; // y el automático, para decirlo aunque se usara otro return out; } /** Quitar los rayados: una línea con muchas paralelas a su lado —de la misma orientación, * solapándose con ella, a menos de `ventana`— no es un muro: es el rayado de una cubierta, los * peldaños de una escalera, la retícula de unas estanterías. Un muro tiene a su lado, como * mucho, su otra cara y el muro de enfrente. Reportado en la revisión con un plano real: la * mitad de lo propuesto era rayado. */ function p2dWallsDropHatching(segs, ventana, vecinos) { const horiz = (s) => s.y1 === s.y2; const c = (s) => horiz(s) ? s.y1 : s.x1, a = (s) => horiz(s) ? s.x1 : s.y1, z = (s) => horiz(s) ? s.x2 : s.y2; // Paralelas, cerca, solapándose, y de un largo parecido: las rayas de un rayado son iguales // entre sí, y un muro junto a ellas —más largo— no cuenta como una más. const largo = (s) => z(s) - a(s); const cerca = (s, q) => horiz(q) === horiz(s) && Math.abs(c(q) - c(s)) <= ventana && Math.min(z(s), z(q)) - Math.max(a(s), a(q)) >= 0.5 * Math.min(largo(s), largo(q)) && Math.abs(largo(q) - largo(s)) <= 0.3 * Math.max(largo(s), largo(q)); const rayado = new Set(); segs.forEach((s, i) => { let n = 0; for (let j = 0; j < segs.length && n < vecinos; j++) if (j !== i && cerca(s, segs[j])) n++; if (n >= vecinos) rayado.add(i); }); // Los bordes de un rayado tienen paralelas solo a un lado y no llegan a la cuenta: una línea // pegada a dos que ya son rayado, y tan larga como ellas, también lo es. segs.forEach((s, i) => { if (rayado.has(i)) return; let n = 0; rayado.forEach(j => { if (cerca(s, segs[j])) n++; }); if (n >= 2) rayado.add(i); }); return segs.filter((_, i) => !rayado.has(i)); } /** Un plano que mezcla estilos —el perímetro en doble línea y los tabiques de dentro con un solo * trazo grueso, que es lo corriente— leído de las dos maneras a la vez. Primero las parejas: dos * líneas a la distancia de un muro son ese muro. De lo que queda sin pareja, solo lo grueso * (`minT` o más): un tabique dibujado de un trazo. Una línea fina y sola no es un muro. Todo de * una lectura: separando antes las finas de las gruesas por su grueso, la cara de un muro doble * que el dibujo hiciera un píxel más gruesa salía como dos tabiques sueltos. */ function p2dWallsMixed(segs, minGap, maxGap, minT) { const sueltos = []; const muros = p2dWallsPairs(segs, minGap, maxGap, sueltos); return p2dWallsDedupe(muros.concat(sueltos.filter(s => s.t >= minT)), maxGap); } /** Un muro, una vez. Dos tramos paralelos, a menos de `maxGap` y solapándose en el 60 % del más * corto, son el mismo muro leído dos veces —como pareja de líneas y como trazo suelto, o sus * dos caras en un plano de muros rellenos—: se queda el más largo, con el grueso del más * grueso. Reportado en la revisión con un plano real: trece muros del perímetro salían dobles. */ function p2dWallsDedupe(segs, maxGap) { const horiz = (s) => s.y1 === s.y2; const c = (s) => horiz(s) ? s.y1 : s.x1, a = (s) => horiz(s) ? s.x1 : s.y1, z = (s) => horiz(s) ? s.x2 : s.y2; const orden = segs.slice().sort((p, q) => (z(q) - a(q)) - (z(p) - a(p))); const out = []; for (const s of orden) { const igual = out.find(q => horiz(q) === horiz(s) && Math.abs(c(q) - c(s)) <= maxGap && Math.min(z(s), z(q)) - Math.max(a(s), a(q)) >= 0.6 * Math.min(z(s) - a(s), z(q) - a(q))); if (igual) igual.t = Math.max(igual.t, s.t); else out.push(Object.assign({}, s)); } return out; } /** Un plano de CAD dibuja un muro como DOS líneas finas paralelas —sus dos caras—, no como un * trazo grueso. Leído como trazos, cada muro salía dos veces, y cualquier línea recta —un * rayado, un mueble, una letra— pasaba por muro. Aquí se buscan parejas: dos líneas de la * misma orientación, a la distancia de un muro (`minGap`..`maxGap`) y que se solapen en al * menos el 60 % de la más corta; cada pareja es UN muro, en medio de las dos y con su grueso * de verdad. Lo que no tiene pareja se queda fuera: casi siempre es lo que no era un muro. * Reportado en la revisión con un plano real: 589 tramos, la mitad de ellos rayados y muebles. */ function p2dWallsPairs(segs, minGap, maxGap, sueltos) { const horiz = (s) => s.y1 === s.y2; const usado = new Set(), out = []; segs.forEach((s, i) => { if (usado.has(i)) return; const h = horiz(s), c = h ? s.y1 : s.x1, a = h ? s.x1 : s.y1, z = h ? s.x2 : s.y2; let mejor = -1, md = Infinity; segs.forEach((q, j) => { if (j === i || usado.has(j) || horiz(q) !== h) return; const cq = h ? q.y1 : q.x1, aq = h ? q.x1 : q.y1, zq = h ? q.x2 : q.y2; const d = Math.abs(cq - c); if (d < minGap || d > maxGap) return; const solape = Math.min(z, zq) - Math.max(a, aq); if (solape < 0.6 * Math.min(z - a, zq - aq)) return; if (d < md) { md = d; mejor = j; } }); if (mejor < 0) { if (sueltos) sueltos.push(s); return; } usado.add(i); usado.add(mejor); const q = segs[mejor]; const cq = h ? q.y1 : q.x1, aq = h ? q.x1 : q.y1, zq = h ? q.x2 : q.y2; const cm = (c + cq) / 2, a0 = Math.min(a, aq), z0 = Math.max(z, zq); const t = md + (s.t + q.t) / 2; out.push(h ? {x1: a0, y1: cm, x2: z0, y2: cm, t} : {x1: cm, y1: a0, x2: cm, y2: z0, t}); }); return out; } //: El grueso mínimo, en píxeles, de un tabique dibujado de un solo trazo. const P2D_WALLS_SOLO_PX = 3; /** Lo que se busca en un plano, en sus píxeles, a partir de su calibración: `{minT, maxT, * minLen, gap, k}` (`k`, milímetros por píxel). */ function p2dWallsParams(k, o) { o = o || {}; const cm = (v) => v * 10 / k; return {minT: Math.max(2, cm(o.minCm || 6)), maxT: Math.max(3, cm(o.maxCm || 70)), minLen: Math.max(8, cm(o.lenCm || 60)), gap: cm(o.gapCm || 30), k}; } /** Los píxeles del plano, a como mucho 3000 px de ancho: más no da más muros, y sí más espera. */ function p2dWallsPixels(data) { return new Promise(ok => { const im = new Image(); im.onload = () => { const k = Math.min(1, 3000 / Math.max(im.naturalWidth || 1, im.naturalHeight || 1)); const cv = document.createElement('canvas'); cv.width = Math.max(1, Math.round((im.naturalWidth || 1) * k)); cv.height = Math.max(1, Math.round((im.naturalHeight || 1) * k)); const g = cv.getContext('2d'); if (!g) return ok(null); g.fillStyle = '#fff'; g.fillRect(0, 0, cv.width, cv.height); g.drawImage(im, 0, 0, cv.width, cv.height); try { ok(g.getImageData(0, 0, cv.width, cv.height)); } catch (_) { ok(null); } }; im.onerror = () => ok(null); im.src = data; }); } // ── Los tramos, en el plano ────────────────────────────────────────────────── /** La distancia de un punto a un tramo, en mm. */ function p2dSegDist(s, x, y) { const dx = s.x2 - s.x1, dy = s.y2 - s.y1, l2 = dx * dx + dy * dy || 1; const k = Math.max(0, Math.min(1, ((x - s.x1) * dx + (y - s.y1) * dy) / l2)); return Math.hypot(x - (s.x1 + k * dx), y - (s.y1 + k * dy)); } /** Si un tramo toca un recuadro (en mm del plano): con cualquier trozo dentro. Lo que el * recuadro del motor pregunta (`touches`) cuando lo elegible son tramos, que su caja —la de un * muro en diagonal— toca mucho más de lo que toca él. */ function p2dSegInBox(s, x0, y0, x1, y1) { // Recortando el tramo con el recuadro (Liang–Barsky): con muestras a lo largo del tramo, un // recuadro pequeño sobre un muro largo caía entre dos y no lo cogía. const xmin = Math.min(x0, x1), xmax = Math.max(x0, x1), ymin = Math.min(y0, y1), ymax = Math.max(y0, y1); const dx = s.x2 - s.x1, dy = s.y2 - s.y1; let t0 = 0, t1 = 1; for (const [p, q] of [[-dx, s.x1 - xmin], [dx, xmax - s.x1], [-dy, s.y1 - ymin], [dy, ymax - s.y1]]) { if (p === 0) { if (q < 0) return false; continue; } const r = q / p; if (p < 0) { if (r > t1) return false; if (r > t0) t0 = r; } else { if (r < t0) return false; if (r < t1) t1 = r; } } return t0 <= t1; } /** Los muros con sus huecos abiertos: una puerta o una ventana dibujada ENCIMA de un muro —que * es como se dibuja— parte ese muro en dos, y el muro deja de tapar el hueco. Sin esto el muro * seguía de suelo a techo por delante de la puerta y del cristal. Un hueco cuenta para un muro * si está sobre su línea: los dos extremos a menos de su grueso (o 30 cm) de ella. */ function p2dWallsCut(segs) { const huecos = segs.filter(s => s.kind === 'door' || s.kind === 'window'); const out = []; for (const s of segs) { if (s.kind !== 'wall') { out.push(s); continue; } const dx = s.x2 - s.x1, dy = s.y2 - s.y1, l2 = dx * dx + dy * dy; if (!l2) continue; const tol = Math.max(300, Number(s.thick_mm) || 0); let trozos = [[0, 1]]; for (const h of huecos) { if (p2dSegDist(s, h.x1, h.y1) > tol || p2dSegDist(s, h.x2, h.y2) > tol) continue; const t1 = ((h.x1 - s.x1) * dx + (h.y1 - s.y1) * dy) / l2; const t2 = ((h.x2 - s.x1) * dx + (h.y2 - s.y1) * dy) / l2; const a = Math.min(t1, t2), b = Math.max(t1, t2); trozos = trozos.flatMap(([p, q]) => (b <= p || a >= q) ? [[p, q]] : [[p, Math.max(p, a)], [Math.min(q, b), q]].filter(([u, v]) => v - u > 1e-3)); } for (const [p, q] of trozos) out.push(Object.assign({}, s, {x1: s.x1 + dx * p, y1: s.y1 + dy * p, x2: s.x1 + dx * q, y2: s.y1 + dy * q})); } return out; }
