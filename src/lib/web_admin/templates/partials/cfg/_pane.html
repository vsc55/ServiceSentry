{# Config section: the markup of its tab pane. Lives with the rest of the section rather than inline in dashboard.html, which is the shell: the panes it used to hold belonged to twelve different sections, so a change to any one of them meant editing the file that renders the whole panel. #}
{# The header (toolbar + search) keeps its natural height and the body below scrolls, which is what actually keeps it on screen. It used to be `position:sticky` instead, and that could not work here: an active tab-pane is a flex column bounded by the viewport (see .container-fluid > .tab-content > .tab-pane.active), so the sticky element's containing block is ONE SCREEN TALL — it pinned for about a screenful of scrolling and then scrolled away with the block that held it, exactly where the config list gets long. The .ss-vfill/.ss-vscroll chain is the mechanism the rest of the panel already uses for this. #}
