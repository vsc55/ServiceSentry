{# Config section: the markup of its tab pane. Lives with the rest of the section rather than inline in dashboard.html, which is the shell: the panes it used to hold belonged to twelve different sections, so a change to any one of them meant editing the file that renders the whole panel. #}
{# The header (toolbar + search) keeps its natural height and the body below scrolls, which is what actually keeps it on screen. It used to be `position:sticky` instead, and that could not work here: an active tab-pane is a flex column bounded by the viewport (see .container-fluid > .tab-content > .tab-pane.active), so the sticky element's containing block is ONE SCREEN TALL — it pinned for about a screenful of scrolling and then scrolled away with the block that held it, exactly where the config list gets long. The .ss-vfill/.ss-vscroll chain is the mechanism the rest of the panel already uses for this. #}

{# "Only what this install changed" — a switch, not a button: it is a MODE that stays on while you work, and a switch is the one control that shows its own state without being pressed. It does not change how the panel is navigated; it narrows what the index lists and what a section shows. #}
{# Collapsed by default: the filter is for finding one setting among many, not something you need in view the rest of the time. Closing it clears the term (see _wiring.html), which is why there is no longer a warning dot here: it existed for the state where a hidden box was still filtering the panel, and that state can no longer happen. A badge for an impossible state is one more thing to keep true. #}
{# No bottom margin: that 1rem strip of page background sat between the card and the scrolling body, and rows sliding underneath surfaced in it — a seam that looked like a rendering fault. The card's own border is the boundary now. The collapse lives on THIS element, not on a wrapper, so the toolbar's `+` sibling selector can see whether it is open and round its own bottom accordingly. #}
{# `cfg-sheet` is what makes a section read as a sheet of options instead of a card — the frame, the chevron and the colour accent belonged to a screen that showed several at once — and it is what pins the section header while the options scroll under it. #}
