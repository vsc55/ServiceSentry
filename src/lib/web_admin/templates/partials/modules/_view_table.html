{# ================================================================ Modules — view: dense table + side panel. For the question the other views answer badly: "which of my modules is not in the state I expect?". A card grid makes you read twelve boxes; a table makes you read one column. The columns are the four things that go wrong — off when it should be on, items disabled, dependencies missing, platform unsupported. Editing happens in a panel over the table rather than in a row: a configuration form inside a table row either squashes the form or wrecks the columns, and the columns are the reason to be in this view at all. ================================================================ #} function _modViewTable(c, names) { const rows = names.map(n => _modRow(_modFacts(n))).join(''); c.innerHTML = `
${rows}
${esc(t('module') || 'Module')} ${esc(t('mod_state') || 'State')} ${esc(t('mod_items') || 'Items')} ${esc(t('mod_warnings') || 'Warnings')}
`; } /** One row. The state is carried by the ROW, not only by the badge in its state column. * * A badge changing from green to grey is the whole signal a table can give if the row stays * the same, and it is a weak one: it is one cell of five, read only if you happen to be * looking at that column. The card views have always dimmed the whole card for this; the * table said it in a corner. `.ss-row-off` gives it the same weight here — a bar down the * edge of the row and its text stepped back — which is what makes "which of these did I turn * off?" answerable by scanning instead of by reading. */ function _modRow(f) { const rowState = f.unavailable ? ' ss-row-warn' : (f.on ? '' : ' ss-row-off'); const state = f.unavailable ? `${esc(t('mod_state_unavailable') || 'Unavailable')}` : (f.on ? `${esc(t('svc_state_running') || 'On')}` : `${esc(t('svc_state_stopped') || 'Off')}`); // The count is worth colouring only when it is telling you something: "3/4" with one item // switched off is a state somebody chose and then forgot about. const items = !f.total ? '—' : `${f.active}/${f.total}`; const warn = _modWarnBadge(f) || '—'; return ` ${_modAvatar(f, 26)} ${esc(f.pretty)} ${esc(f.name)} ${state} ${items} ${warn} ${f.unavailable ? '' : _modSwitch(f)} ${f.unavailable ? '' : ``} ${_modDeleteBtn(f)} `; }
