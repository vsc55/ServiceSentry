{# ================================================================ Modules — view: list | detail. The one that answers what the card grid could not: a module's configuration is wide, and a 420px grid cell is not. That layout already admitted it, with a "full screen" button that reopened the same body in a modal — a workaround for the container, not a feature. Here the list stays narrow and scrolls on its own, and the selected module gets the whole remaining width. Nothing grows, so nothing reflows: expanding an item moves the detail pane's scrollbar and leaves everything else where it was.
