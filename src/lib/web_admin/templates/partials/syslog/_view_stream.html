{# ================================================================ Syslog — stream: the log the shape a log is read in. A grid makes you re-read five column headers per line to follow one machine's story, and spends a third of the width on chrome. A console line puts the severity, the clock, the host and the text where the eye already expects them, fits about twice as many lines on a screen, and lets the message run to the full width instead of wrapping inside a cell. Same rows, same order, same page as the table: the server decided which ones those are. The date is stated once per day rather than repeated on every line — a log read at 3am is almost always one day's worth, and the column that repeats the same eight characters two hundred times is the one worth removing. ================================================================ #} function _slViewStream(rows) { let out = '', day = null; for (const m of rows) { const d = _slDay(m); if (d !== day) { day = d; out += `
${esc(d)}
`; } out += _slStreamLine(m); } return `
${out}
`; } function _slStreamLine(m) { // The severity is a coloured bar down the left AND a name in the line: colour alone // would leave the stream unreadable to anyone who cannot separate the reds from the // greys, and this is the view with the least other context to fall back on. const cls = _slSevClass(m); const host = _slHost(m), app = _slApp(m); return `
${esc(_slClock(m))} ${_slSevBadge(m)} ${host ? `${esc(host)}` : ''} ${app ? `${esc(app)}` : ''} ${esc(m.message || '')}
`; }
