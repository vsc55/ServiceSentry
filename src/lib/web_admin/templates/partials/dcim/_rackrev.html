Guardando sólo lo segundo no se puede reconstruir lo primero sin reproducirlo todo, y basta que falte un renglón para que la reconstrucción mienta sin decirlo. La lista se lee como una bitácora; abriendo dos se comparan. Lo que no entra es el cableado ni la alimentación: tienen sus propias pantallas, y meterlos aquí haría que enchufar un latiguillo generase una versión — un historial donde nueve de cada diez renglones son ruido es uno que nadie abre. ================================================================ #} //: Las versiones del armario abierto, o `null` mientras no se han pedido. let _dcHist = null; //: Las dos que se están comparando, por uid.
