{# ================================================================ DCIM — los muros de una planta, leídos del plano del arquitecto. Se pidió que el plano de fondo diera los muros, en vez de tener que dibujarlos. Lo que se hace aquí es proponerlos: el plano se lee en el navegador —sin librerías— buscando trazos oscuros con el grosor de un muro, rectos y largos, y lo que sale se dibuja encima del plano en naranja. Quien lo mira acepta, borra, alarga o dibuja lo que falte, y al guardar la planta tiene sus muros: el 3D de la planta y del edificio los levanta. Proponer y revisar, no generar y ya: un plano trae cotas, textos, rayados y muebles que se parecen a un muro, y escaneado trae sombras. Lo que pasa los filtros es casi siempre un muro; lo que falta o sobra se arregla en un minuto, y el plano no decide solo lo que el edificio es. Sin calibrar, unas medidas típicas — y un aviso, porque los metros saldrán mal. ================================================================ #} // ── Leer el plano ──────────────────────────────────────────────────────────── /** El umbral de Otsu: el gris que mejor separa el trazo del fondo. */ function _dcwOtsu(lum) { const hist = new Array(256).fill(0); for (let i = 0; i < lum.length; i++) hist[lum[i]]++; const total = lum.length; let suma = 0; for (let i = 0; i < 256; i++) suma += i * hist[i]; let sB = 0, wB = 0, mejor = 0, umbral = 128; for (let i = 0; i < 256; i++) { wB += hist[i]; if (!wB) continue; const wF = total - wB; if (!wF) break; sB += i * hist[i]; const mB = sB / wB, mF = (suma - sB) / wF; const entre = wB * wF * (mB - mF) * (mB - mF); if (entre > mejor) { mejor = entre; umbral = i; } } return umbral; } /** Los tramos de muro de una imagen: `[{x1, y1, x2, y2, t}]` en píxeles, `t` su grueso. * * Horizontales y verticales por separado, con la misma cuenta girada: por cada fila, los trozos * oscuros de al menos `minLen` seguidos; las filas contiguas cuyos trozos se solapan son el * mismo trazo, y su número de filas es su grueso.
