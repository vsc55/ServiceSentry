Six sections draw this: Overview, Status, History, Syslog, the Servers monitoring panel and the cluster modal. It lived inside overview/_render.html — its own comment said "shared across Status / Overview / History" and it stayed there anyway — which made a control every section depends on a thing you had to know was hiding in one of them. Same mistake as a generic module runner living in the hosts domain: a section's file is for what only that section does. What it is: a split button whose main side refreshes now and whose caret opens the interval menu (OFF / Auto / presets / a free seconds field). "Auto" mirrors the background scheduler's own interval and is disabled while it is stopped, which is why the scheduler state lives here too — it exists for this menu.
