{# ================================================================ Backup — the retention policy of a task, and what it would actually do. A counter answers "how many do I keep?". The question worth answering is "how far back can I go, and at what resolution?" — and seven copies can be one week at daily resolution or two years at monthly. Only the second survives finding out in March that something broke in January. Which is also what made this the longest block on the form: five numbers and a ceiling, retyped in every task from memory. So a task either states its own policy or FOLLOWS a profile — and the boxes only appear for the first, which is what keeps the editor short in the case where somebody has already decided how much history this install keeps. Its own partial because the preview is the half that makes the rest usable: nobody can evaluate "7 daily + 4 weekly + 6 monthly" against 200 files in their head, and a policy nobody can predict is a policy nobody dares touch. ================================================================ #} // The buckets, in the order they read: the newest few, then coarser and further back. const _BK_BUCKETS = [ ['keep_last', 'backup_keep_last'], ['keep_daily', 'backup_keep_daily'], ['keep_weekly', 'backup_keep_weekly'], ['keep_monthly', 'backup_keep_monthly'], ['keep_yearly', 'backup_keep_yearly'], ]; const _BK_MIB = 1024 * 1024; /** The retention fields. `; const mib = Math.round((Number(src.max_size) || 0) / _BK_MIB); return `
${_BK_BUCKETS.map(b => box(b[0], b[1])).join('')}
${esc(t('backup_retention_hint'))}
MiB
${esc(t('backup_max_size_hint'))}
`; } /** The five numbers as read back out of a form drawn with `_bkBucketBoxes`. */ function _bkBucketValues(prefix) { const out = {}; for (const [key] of _BK_BUCKETS) { out[key] = Number(document.getElementById(prefix + key)?.value || 0); } // Bytes on the wire, MiB in the box: an operator types a round number and the rule is // enforced against real file sizes. out.max_size = Number(document.getElementById(prefix + 'max_size')?.value || 0) * _BK_MIB; return out; } /** The Retention tab of the task editor: whose policy this is, and what it would do. * * The task's own numbers stay in the form even while a profile is selected — hidden, not * discarded.
