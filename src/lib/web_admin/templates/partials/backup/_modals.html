{# One modal for both jobs — making a copy and putting one back. Its own rather than borrowed: `showConfirmModal` takes a line of TEXT (it sets `.textContent`, deliberately, so a message can never inject markup) and this needs a form. `showInfoModal` shows key/value pairs and has no confirm button at all. The body and the confirm button are filled by _render.html; what lives here is the shell, so the markup is in a template like every other modal instead of being built from strings at run time. #}
