How old that is depends on the scheduler interval, and for a device sampled by a full SNMP profile on the minutes the sampling itself takes — a Synology answers about a thousand values and takes roughly five. Somebody who has just replaced a disk should not have to wait for a tick, and the only way to ask used to be the Status screen's "run all": every module, every machine. FOUR THINGS THIS FILE IS ABOUT, and they are all the same complaint: * a run that shows nothing until it ends is indistinguishable from one that has hung, so there is a CHECKLIST — one line per thing being done, and under a module that counts its own work, the phases it named for itself with how far along each is.
