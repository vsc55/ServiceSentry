{# ================================================================ Infrastructure — everything the device answered, unarranged. Every other tab is an OPINION about this data: Details picks the handful that answer "is this box all right", Measures groups by the profile that produced each value and hides the quiet tail behind a button, the row dialog gathers one disk's story. Opinions are what make a screen readable, and they are also what makes it impossible to answer "is the panel even receiving that OID" — because every one of them can drop a value for a reason that looked sensible when it was written. So this tab has no opinion. One line per reading, in the order the server sent them, with the coordinates that identify it: which check, which profile, which row, which field. It is the tab you open when a number looks wrong somewhere else, and the one that tells you whether the problem is the device, the profile or the screen. It is deliberately the LAST tab and never the default: a thousand undifferentiated lines is the right answer to a question nobody has asked yet. ================================================================ #} //: How many readings are drawn before the rest go behind a button.
