${esc(t('infra_no_checks'))}

${esc(t('infra_no_checks'))}

${body}

Reported from the screen: the column ran // for pages. One SNMP item files a result per disk, per volume, per share, and each of // them carries a model and a serial — so "the identity of this machine" became two // hundred blocks, which is not an identity, it is an inventory. A row's facts belong // beside that row; this column answers "what is this box". // // Grouped by source and not merged. One registry entry can front several pieces of // equipment — a NAS and the UPS plugged into it both answer "vendor", "model", "version" // — and side by side under one heading they read as one machine with contradictory facts. const groups = new Map(); // …and, beside them, the values that answer "what is this" rather than "how is it doing". // "Is there an update" is a property of the box and belongs next to the DSM version it is // about, not among the temperatures on the summary. Which values those are is the // profile's word (`identity`), so the panel does not learn what an update is. for (const m of (d.metrics || []).filter(m => m.identity && !m.row)) { const k = m.source || ''; if (!groups.has(k)) groups.set(k, {source: k, label: m.source_label || k, short: m.source_short || '', facts: [], states: []}); groups.get(k).states.push(m); } for (const a of attrs.filter(a => !a.row)) { const k = a.source || ''; // Insertion order IS the order: the server sorted them (standards before a vendor's // own MIB — see infra.service.attributes) and a Map keeps what it was given. `).join('')}
`; // A state reads as a word and not as a row of a definition list: "Actualización // disponible: Disponible" is the same word twice. '' : `
${list.map(m => `
${m.icon ? `` : ''}${esc(m.label || m.field)}
${_infraValueHtml(m)}
`).join('')}
`; const block = (title, list, note, st) => `
${esc(title)} ${note ? `${esc(note)}` : ''}
${facts(list, st)}${states(loose(st, list))}
`; // The source is the heading: a fact about the device still belongs to whichever of its // parts answered it, and "the UPS says its model is X" is a different statement from // "the NAS says its model is X". // // And with NO source, the heading must not be "Identity". That case is a sample written // before the source was recorded — the facts of a NAS and of the UPS plugged into it, in // one pile, with no way left to tell which said what. Calling that pile the machine's // identity is the panel asserting exactly the thing it cannot know, and it is how a UPS's // model came to be read as the NAS's in the first place. Named for what it is instead, so // it reads as "these need collecting again" rather than as an answer. // The name the source gives itself, per language — not its id. The ids were being printed // raw ("synology_ups") beside values that were translated, which is the panel showing its // own filing system to somebody who asked what the machine is. // The name the profile gives the THING, when it gives one — "Synology", "SAI". Falling // back to the trimmed title, which is right for the profiles that describe the box itself // and wrong for the ones that describe something attached to it: "Synology — SAI" trims to // "Synology — SAI", and what belongs on that card is "SAI". No rule about the text can // tell those apart, so the profile says. const head = g => g.source ? (g.short || _infraShortLabel(g.label || g.source)) : t('infra_identity_unsourced'); const sub = () => ''; // The registry's own record is not a set of attributes, so it is handed over in the same // shape: a key the labeller knows and a value. const regFacts = reg.map(([k, v]) => ({key: '', label: k, value: v})); return `${reg.length ? block(t('infra_record'), regFacts) : ''} ${[...groups.values()].map(g => block(head(g), g.facts, sub(g), g.states)).join('')} ${!reg.length && !attrs.length && !groups.size ? `
${esc(t('infra_no_identity'))}
` : ''}`; } /** The name of one such fact. An unknown role falls back to its own key: a word somebody has to * guess at beats a fact that is not shown. */ function _attrLabel(key) { return t('attr_' + key) || key; }
