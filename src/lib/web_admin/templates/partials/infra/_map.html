{# ================================================================ Infrastructure — how the fleet is wired together, drawn. Every line here is INFERRED, and the drawing has to keep saying so. What the panel knows is which addresses each machine claims, which network each of those sits on, and where each machine sends what it cannot deliver itself. From that: two machines on one network can reach each other, and a machine points at its way out. What it does NOT know is which port is plugged into which port — that is LLDP, and nothing in this fleet serves it yet. So there are two kinds of line and they are drawn differently on purpose. A machine sitting in a network's lane is a fact about addresses. An arrow to a gateway is a statement the device itself made. Flattening them into "connected" would be the picture claiming more than the data does, which is the one thing a map must not do. Hand-written SVG because the page is self-contained: no CDN, no layout library. The layout is therefore deliberately dumb — a lane per network, boxes wrapped inside it — which has the advantage that it cannot produce the hairball a force layout produces on a flat /24. ================================================================ #} //: The last map the server sent, and whether we are asking for one.
