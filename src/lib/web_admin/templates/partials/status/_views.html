{# ================================================================ Status — the part every view shares. Status is a MONITORING surface, so the views differ in one thing: how quickly they answer "what is broken right now". The card grid answers it slowly — you scroll past everything green to find the two that are not. What must not differ is what a check MEANS. Whether a result is ok / warning / error, what its display name is, and the value-vs-threshold decoration a module declares in its schema (__status_render__) are decided once, here, and every view draws from that.
