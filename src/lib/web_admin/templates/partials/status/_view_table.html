{# ================================================================ Status — view: one row per CHECK. The card grid groups by module, which is the right grouping for configuring and the wrong one for triage: "what is broken right now" is a question about checks, and the answer is currently spread across however many cards happen to contain a failure. Flattened, the failures are the first rows and everything about them — module, check, reason, value against threshold — is on one line, comparable at a glance. It is also the view that survives scale: three hundred checks is three hundred rows, where it would be forty cards to open. Sorted worst first by default, for the same reason the summary view is: the page should not make you look for what it already knows. ================================================================ #} function _stViewTable(c, data) { const tt = _stTotals(data); // Flatten to checks, keeping the module order _stVisible decided (worst first) and // ordering within a module the same way, so the very first row is the worst thing there is. const rank = { error: 0, warn: 1, none: 2, ok: 3 }; const rows = []; for (const [, , st] of _stVisible(data)) { rows.push(..._stShownRows(st).sort((a, b) => rank[a.state] - rank[b.state] || a.name.localeCompare(b.name))); } const q = _stFilterTerm.trim().toLowerCase(); // The module filter already ran; narrowing to matching CHECKS only makes sense once the // term actually matches some, or searching a module name would empty its own rows. const shown = (q && rows.some(r => r.name.toLowerCase().includes(q))) ? rows.filter(r => r.name.toLowerCase().includes(q)) : rows; c.innerHTML = ` ${_stResultsHeader(tt)} ${shown.length ? `
${shown.map(_stTableRow).join('')}
${esc(t('mod_state'))} ${esc(t('module'))} ${esc(t('st_check'))}
` : _stEmptyState()}`; } function _stTableRow(f) { const pretty = modulePrettyName(f.mod, modulesData[f.mod] || {}); return ` ${_stStateIcon(f, '.85rem')}${_stStatePill(f)} ${esc(pretty)}
${esc(f.name)}
${f.msg ? `
${esc(f.msg)}
` : ''} ${f.extraHtml} `; }
